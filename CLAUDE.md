## Constraints & Styling Rules
- **HTML5, CSS3, and Bootstrap 5 ONLY. NO custom JavaScript.**
- **Comments:** Add clear comments above HTML sections and CSS blocks explaining **what** the code is and **why** it is there across all files.
- **Comic Book Strip Aesthetic:** London Underground Red & Blue palette paired with harmonious accents (e.g. via Coolors), warning yellow, bold ink borders/shadows, `'Bangers'` Google Font for headings/buttons/hero display text (with subtle tilt/rotation on first letter/word or buttons where appropriate), and standard readable fonts for body text and copyright footers.
- **Desktop-first polish with full responsive support** across tablet and mobile viewports.
